
# Saber+

Sistema de gerenciamento de acervo para biblioteca


## Tecnologias utilizadas

- Vite
- React
- Axios
- React-Router-Dom


## Rodar Localmente

Clone o projeto

```bash
  git clone https://link-to-project
```

Va para o diretorio do projeto

```bash
  cd my-project
```

Instale as dependencias

```bash
  npm install
```

Modifique a url base da api no seguinte caminho

```bash
  src/services/api.js
```
Inicie o servidor

```bash
  npm run dev
```
